Akasavani is a friendly local web UI for text-to-speech. Type your text, pick English or తెలుగు (Telugu), set the speed from 0 to 3×, and hear it instantly — all on your own hardware. No cloud, no per-character fees.

Features

🎚️ Speed 0–3×

Slow down fast talkers or speed up long reads. The slider maps to the model's length scale, so it works for VITS and XTTS.

🗣️ English & తెలుగు

A short, curated set of English voices from vctk/vits, plus native Telugu with three Piper voices — switch language from one dropdown.

🖱️ One double-click

On Windows, Start Web UI.bat boots the server and opens your browser. Nothing else to configure.

🔒 100% local

Your text never leaves your machine. No API keys, no accounts, no usage limits.

🧩 Clean REST API

Also exposes an OpenAI-compatible /v1/audio/speech endpoint, so you can script it.

🐳 Docker ready

A Dockerfile and docker-compose.yml are included for reproducible, cross-platform runs.

How to run it

Option A — Windows, one double-click

  1. Download or clone this repo.
  2. Double-click Start Web UI.bat.
  3. Your browser opens at http://localhost:5002. Type, pick a voice, Speak.

Option B — Any OS, with Python 3.11

git clone https://github.com/vvsnmurthy3758/akasavani.git
cd akasavani
python -m venv .venv
.venv/Scripts/activate        # Windows
# source .venv/bin/activate   # macOS / Linux
pip install -r requirements.txt
pip install espeak-ng        # or install it from your package manager
tts-server --model_name tts_models/en/vctk/vits --port 5002

Then open http://localhost:5002. First run downloads the model (~150 MB).

Option C — Docker

docker compose up --build

Then open http://localhost:5002. For GPU, uncomment the deploy block in docker-compose.yml.
