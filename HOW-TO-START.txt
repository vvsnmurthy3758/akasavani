HOW TO START AKASAVANI
======================

1. Open this folder:   D:\svb01\akasavani
2. Double-click:       Start Web UI.bat
3. A black window opens and your browser opens by itself.
   (If it doesn't open, go to:  http://localhost:5002 )
4. Type some text, pick a language (English or Telugu), click Speak.
5. SPEED: use the "Speed" slider under the text box.
   0 = slowest, 1 = normal, 3 = fastest. Move it, then click Speak.
6. TELUGU: choose "తెలుగు (Telugu)" in the Language box. The first time
   you use it, it downloads a Telugu voice (~145 MB) - after that it is fast.
7. To stop: close the black window, or press Ctrl+C in it.

That's all. The first time takes longer because it downloads the voice model.
Every time after that, it starts fast.


------------------------------------------------------------
IF THE FOLDER IS MOVED OR THE ENVIRONMENT IS MISSING
------------------------------------------------------------
The big ".venv" folder is NOT inside this backup (it was 4.79 GB and does
not move between computers). If it is missing, rebuild it once with these
commands (run them in the akasavani folder):

  uv venv --python 3.11 ".venv"
  uv pip install --python ".venv\Scripts\python.exe" torch==2.4.1 torchaudio==2.4.1 --index-url https://download.pytorch.org/whl/cu121
  uv pip install --python ".venv\Scripts\python.exe" "coqui-tts[server]" six
  uv pip install --python ".venv\Scripts\python.exe" transformers==4.57.1 huggingface-hub==0.36.2 tokenizers==0.22.2 soundfile librosa

(transformers must stay on the 4.x line: version 5 needs torch 2.6, which
would break the CUDA 12.1 build above.)

Then also install espeak-ng (needed by the vctk/vits voice model):

  winget install eSpeak-NG.eSpeak-NG

ABOUT THE SPEED SLIDER
After rebuilding, the "Speed" slider comes from the "patches" folder next to
this file. You don't have to do anything: start_webui.py copies the patched
server.py and index.html into the .venv every time it starts, so the slider
always works. (Keep the "patches" folder with this backup.)

Full details are in README.md.
